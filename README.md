# ISS – Industrielle Steuerungssysteme (SPS-Projekt)

Übungen und Abgaben zum Modul **II2003 Industrielle Steuerungssysteme**, umgesetzt mit **CODESYS V3** (IEC 61131-3).

## Inhalt

| Ordner | Beschreibung |
|---|---|
| `Abgabe_1_5460715/` | Abgabe 1 – Übungen 1.2 bis 1.7 (CODESYS-Projekte + Screenshots) |
| `Abgabe_2_5460715/` | Abgabe 2 – Übung 1.1.1 (CODESYS-Projekt + Screenshot) |
| `II2003_5512544_Industrielle_Steuerungssysteme_Uebungen/` | Wochenübungen (Dienstag–Freitag, CODESYS-Projekte) und Flussdiagramm |

## Öffnen

Die `.project`-Dateien mit **CODESYS V3.5** öffnen. Die Steuerung läuft in der Simulation mit `CODESYS Control Win V3 x64`.
Compile-Caches und benutzerspezifische `.opt`-Dateien sind nicht im Repository, CODESYS erzeugt sie beim Übersetzen neu.
